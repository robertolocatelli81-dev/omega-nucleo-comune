# Security

Report a vulnerability privately: on this repository, Security → Report a vulnerability
(https://github.com/robertolocatelli81-dev/omega-nucleo-comune/security/advisories/new). Please do not open a public
issue for it.

The latest commit of `main` is the supported version. A work that carries a copy of the core is corrected by copying
the new core into it (`nucleo_sync.py copy`); `nucleo_sync.py check` names a copy that was left behind.

What the modules do not do is written in their docstrings and in DIFFERENZE.md.
